# @javierfrancoleal/audit

Created by **J.Franco** — the consolidation organ of the workflow v2.

## The honest evolution story

The original organism had nine organs. The industrial lens showed that
five were redundant: `usage-auditor` and `triage` read the same logs the
grader reads. Their protocols were folded into ONE organ — `audit` — so
the logs are read once and every output is produced in a single pass.

The five vestigial organs (`interpreter`, `input-detector`, `cortex`,
`triage`, `usage-auditor`) remain published on npm as deprecated: kept in
the genome, no longer in the active body — like the appendix.

## Use this plugin

Ask "audit" or use `/audit` in a session, weekly.
