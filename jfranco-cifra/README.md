# @javierfrancoleal/cifra

Created by **J.Franco**.

## Summary

When a Fanal skin must adapt to its host (macOS, Windows, Linux, iOS,
Android; laptop, tablet, smartphone), this skill applies the canonical
host signature (assets/host-detect.js), the OS-adaptive text matrix, and
the audit rule: the signature is always visible to the operator.
