# @javierfrancoleal/forensics

Created by **J.Franco**.

## Summary

AI writes the code; the human reconstructs it. The forensics organ is the
archaeological protocol: identify the layers, trace ONE feature end to
end, read the fossil record (commits, LEARNINGS, triage, audit), and
produce a plain-language dossier that lets a non-programmer give correct
orders.

## Use this plugin

Ask "forensics" or use `/forensics <feature>` (e.g. `/forensics the
virtual register`).
