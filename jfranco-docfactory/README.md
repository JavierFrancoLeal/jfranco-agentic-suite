# @javierfrancoleal/docfactory

Created by **J.Franco**.

## Summary

When the model creates professional documents (business plans, one-pagers,
agreements), this skill applies consulting-grade techniques — boxes that
never split across pages (cantSplit + keep-next chains), repeating table
headers, no orphan/widow lines, page numbers, document metadata,
consistent hyperlinks — plus the Trasunto editorial DNA (no
meta-pointers, narrative flow, modest numbers, no over-promising, one
concept defined once).

## Use

Ask "docfactory" before creating or polishing any Word/PDF document.
The skill points to the reusable `docfx.py` library (in the plugin
assets) that implements every technique.
