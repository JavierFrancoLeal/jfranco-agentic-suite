# @javierfrancoleal/conductor

Created by **J.Franco**.

## Summary

For vibe coding: when the human's directions are vague and friction
appears (repeated revisions, "no funciona", frustration), the conductor
delivers ONE micro-lesson — the relevant basic concept (layers, flow,
timeline, components, color, animation, design system) in the user's own
language, with a prompt template and one clarifying question.

The full curriculum lives in the suite's `docs/CONDUCTOR-GUIDE.md`.

## Use this plugin

Ask "conductor" or use `/conductor "what the user said"` when a request
gets stuck. The organ detects the friction signal, teaches once, and
returns to work.
