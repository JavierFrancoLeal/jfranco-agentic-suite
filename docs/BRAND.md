# Fanal — brand system (antifragile)

*The AI works. The human watches, decides, reviews.* 🍁

## The story

**Veilleux** comes from *veiller* — to keep watch, to look after, and in
Quebec, *"je vais veiller à ça"*: I will see to it / review it later. The
name itself is the reminder: the AI proposes, the human **reviews**. The
mark joins an **eye that never sleeps** with the **flame of the veillée**,
the Quebec tradition of gathering to keep vigil by the fire.

## The mark, distilled (lessons from the greats)

| Lesson | Source | How we honor it |
|---|---|---|
| Survive monochrome | Apple's 1998 distillation | `le-veilleux-mono.svg` (all-ink) and `le-veilleux-white.svg` |
| A redrawable glyph | Slack's octothorpe | The flame-pupil: one stroke + one drop |
| Own a color territory | Instagram's gradient | Blue `#4D6BFE` → violet `#7c5cff` + flame amber `#FACC15` |
| Motion-ready | Netflix's animated N | The flame flickers subtly on the login screen |
| Works at 16 px | Linear/Vercel minimalism | Favicon = the mark; readable at any size |
| Never discard equity | Twitter→X warning | We iterate and distill, never rebrand |

## Color tokens

| Token | Value | Use |
|---|---|---|
| Blue | `#4D6BFE` | Primary, buttons, gradient start |
| Violet | `#7C5CFF` | Gradient end, accents |
| Flame amber | `#FACC15` | The flame pupil, warnings |
| Ink | `#101828` | Text on light |
| Paper | `#F6F7FB` | Backgrounds |

## Lockups

- `le-veilleux-mark.svg` — the mark alone (avatars, favicons, app icons).
- `le-veilleux-logo.svg` — mark + wordmark + tagline (login, headers).
- `le-veilleux-mono.svg` / `le-veilleux-white.svg` — one-color (print,
  dark backgrounds, documents).
- Wordmark hierarchy: **Le** (medium) + **Veilleux** (bold).

## Usage rules

1. Never stretch, rotate, or recolor the mark.
2. Minimum size: 24 px (16 px favicon excepted).
3. On photos, use the white or mono version.
4. The flame is the signature: never separate it from the eye.
