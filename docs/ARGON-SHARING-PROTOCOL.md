# ARGON-SHARING-PROTOCOL — how the director shares Argon's answers (2026-11-08)

The house rule: ONE exchange per message (the director's proposal —
adopted). And the division of labor that protects the attention and
loses nothing:

- The FULL Argon answer → saved as a file in docs/ARGON-REVIEWS/
  (argon-NN.md) and git-committed. Nothing is lost; the file is read
  when a detail is needed.
- The MESSAGE to the Lead → the DIGEST, in exactly four parts:

  1. THE QUESTION (one line — what was asked).
  2. THE VERDICT (Argon's one-line verdict, verbatim — the core).
  3. THE CHANGES (the concrete proposals condensed: the rules and the
     structure — the full code blocks can stay in the file; the Lead
     rebuilds in the house style anyway).
  4. THE NO HAGAS + 1-2 key rows of the numbers (the decision inputs).

The code blocks, the full tables and the repetitions stay in the file;
only the decision-relevant content travels in the message. Order the
exchanges by priority: the ones with adoptable code first.
