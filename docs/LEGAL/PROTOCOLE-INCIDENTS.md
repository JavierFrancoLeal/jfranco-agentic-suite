# Protocole de gestion des incidents de confidentialité

*Loi 25, art. 3.5-3.8. Version 1.0, 2026-11-06.*

## Le journal

Tout incident présumé est consigné dans ~/.dsh/incidents.md (le journal
local de Trasunto) avec : date, description, données en cause, mesures.

## Les trois degrés

1. **Bénin** (aucun risque de préjudice sérieux) → consigner, corriger.
2. **Préjudice sérieux possible** → aviser la **CAI** sans délai
   (objectif : au plus tard 72 h après la connaissance) + aviser les
   personnes concernées si le risque le justifie.
3. **Urgence** → mêmes avis + contenir d'abord (couper l'accès,
   révoquer les jetons, préserver les preuves).

## La règle de la maison

Un incident ne se cache jamais : il se consigne, s'évalue et se
déclare. La transparence est le produit.
