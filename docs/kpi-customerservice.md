# KPI template — Customer Service

| KPI | Definition | How the log provides it |
|---|---|---|
| Customers served | service sessions per period | session entries |
| Automatic actions per customer | (GREEN + SEMI actions) / sessions | action counts |
| Proposal approval rate | approved proposals / total | decision lines |
| Refund/exchange escalations | escalations raised (RED, never automatic) | RED lines |
| Interpretation sessions | bilingual conversations handled | interpreter entries |
| Corrections per shift | human corrections / sessions | correction lines |
| Autonomy level | 1-5 from the pattern grades | grader |

## Trends

Report each KPI with its previous-period value and direction (up / flat /
down). The owner acts on trends, not on single numbers.
