# BRANCH-AGENTS — the personal agents of each administration branch

*One agent per branch of business administration (legal, accounting,
finance, marketing, economics). The agent PREPARES; the certified
professional VALIDATES and signs. Inspired by Claude's Personal Finance
(Nov 5, 2026) and by the house doctrine. 2026-11-07.*

## What Claude's Personal Finance teaches us

Anthropic's feature: READ-ONLY access to the user's OWN accounts
(connected by the user themselves through Plaid — no password seen),
answers in plain language, no ads, no sponsored products, and the
explicit closing line: "people are best served by Claude working
ALONGSIDE the licensed professionals and regulated firms they trust."
That is the same doctrine: the tool understands, the professional
decides. Fanal's branch agents are that, per branch, for the PME.

## The five branches

| Branch | The agent PREPARES (from the client's own silo) | The certified professional VALIDATES |
|---|---|---|
| ⚖️ Juridique | contracts drafted with the required clauses, policy skeletons, the Loi 25 documents | the lawyer reviews and signs |
| 🧮 Comptable | reconciled books, the arithmetic invariants (sums to the cent), tax-prep drafts | the accountant certifies |
| 💰 Financier | cash flow, budgets, projections, the daily-budget guards | the advisor approves |
| 📣 Marketing | campaigns, content, sector benchmarks | the agency/owner approves |
| 📈 Économique | pricing under the constitution (minimum price), supply/demand notes | the owner decides |

## The architecture (the same organism, one cage per branch)

Each branch = (1) a Studio task type; (2) its DETERMINISTIC CAGE: the
validators of that branch (accounting: the cent-level arithmetic;
legal: the required-clauses checklist; finance: the budget guards;
marketing: the tone and the Loi 25 checks; economics: the price floor
in digits and words); (3) the constitution section with the branch's
rules; (4) the EXPORT PACKAGE: the docfactory builds the "dossier de
validation" — the prepared work plus the list of what the professional
must verify; (5) the professional's signature is the RECORD: the
bilateral accountability extends to the certified third party, whose
skin (license, insurance, reputation) is the last validator.

## The KPI

The agent's value = the professional's time saved: the pre-work arrives
90% done, so the certified hour costs less and the PME pays less. The
correction metric counts the professional's edits — the same negative
signal as the human's corrections.

## The rule of the house

The branch agents never impersonate the professions: they never give a
legal opinion, never sign a return, never recommend an investment. They
prepare, explain and cite — the license signs.

## The expanded professions (all the economic sectors)

The same pattern extends to every sector: the agent prepares, the
certified professional validates.

| Branch | Prepares | The certified validator |
|---|---|---|
| insurance | coverage comparisons, exclusion lists | the broker |
| hr | payroll, schedules, contract templates | the HR professional |
| realestate | comparables, standard documents | the OACIQ broker |
| foodsafety | cleaning plans, MAPAQ registers | the inspector |
| importexport | customs classifications, documents | the customs broker |

| education | lesson plans, parent communications | the teacher |
| auto | workshop quotes, histories | the certified mechanic |

The rule is identical everywhere: PREPARE, EXPLAIN, CITE — the license
signs. Each branch is a plug for the same organism.
