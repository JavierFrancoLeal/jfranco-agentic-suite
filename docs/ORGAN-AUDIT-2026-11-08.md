*The audit the director asked: with the new technology (the triage,
the apices registry, the capsule, the armor, the qualifier, the
zero-hardware profile), what happens to the organs? The verdict with
the nature lens.*

## The rule that governs the answer (the epigenetic law)

The SERVER is the BODY — every new capability lives there as code (the
triage, the registry, the capsule, the armor, the qualifier, the
profile all live in supervisor/server.js). The ORGANS are the
SENSES/REFLEXES the agent needs INSIDE a DSH session — a new organ is
born only when a new REFLEX is needed, never one per feature. The
demand decides the activation: nothing grows without a client's money.

  the literal sourcePin doctrine, the max-5 rule and the locked
  signature — dormant in the vestigial genome until the Beta's demand
  activates it. The registry itself already lives in the server.
- NOT ORGANS (they belong to the body): the .fanal capsule and the key
  recovery (the server's crypto), the armor (the server's guard), the

  hardware profile (the server's runtime), the financial model (the
