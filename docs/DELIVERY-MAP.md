## The installation & training flow (Day 0 – Day 14)

### Day 0 — Installation (2 h on site)

- **Hardware:** ONE computer for the owner (existing or new) = the brain
  (supervisor server + DSH runtime + API key). Workers use their existing
  tablets/phones — nothing to install, just the URL or the installed PWA.
  Optional: a kitchen/back-office tablet.
- **Software:** Fanal Desktop (Electron) or the `jfranco-supervisor`
  npm package; the DSH profile with the 7 organs; the DeepSeek API key
  (Trasunto's during the pilot, the client's afterwards).
- **Check:** the 3-screen first run (language once → brand transition →
  login) + the owner account creation.

### Day 1 — Training by role (90 minutes)

- Owner (30 min): dashboard, register, Z-report, workers management.
- Lead (30 min): orders, kitchen flow, notifications.
- Team (30 min): the panel, dictation, START/STOP.
- The app trains itself afterwards: 10 languages, guided screens, the
  version badge — no manual needed on site.

### Day 2–14 — Accompaniment (the pilot)

- 1 h/week of honest feedback (test – feedback – adjust).
- The service façons (01–04, 07–08) are delivered REMOTELY by Franco
  Vision with DSH — zero installation at the client's premises.

## The rule

> Installed = the daily loop (Fanal). Delivered = the custom
> automations (DSH service). The guide labels each façon so the client
> never confuses what they own from what they hire.
