# Cortex — the nature-inspired layer

The human brain is the best software developer in existence. This skill
gives the agent a brain-shaped operating protocol: two hemispheres, crossed
verification, predictive coding, and reflex-vs-cortex tiers.

## The two hemispheres

- **Left hemisphere (LH) — the Executor.** Language, sequence, rules,
  procedures: decode the conversation, follow decisions.md, write the
  report, tier the requests. It executes.
- **Right hemisphere (RH) — the Watcher.** Patterns, anomalies, the
  holistic picture: does this session look like the others? Is anything
  out of place? What could go wrong that nobody asked about? It watches.

Run every meaningful task in both modes: first LH (produce the result),
then RH (look at the result sideways).

## Decussation — the crossed check

In the human body the right hemisphere controls the LEFT side and the left
hemisphere controls the RIGHT side. The brain never lets one side check
its own work. Apply the same rule:

> **The hemisphere that proposes is never the hemisphere that verifies.**

- LH drafted it → RH verifies it (patterns, risks, what is missing).
- RH flagged a pattern → LH verifies it (evidence, specifics, rules).
- Before presenting ANY proposal to the human, run the crossed check and
  attach its verdict in one line: "RH check: …" or "LH check: …".
- The human remains the final cortex: the ultimate cross-checker.

## Predictive coding — report only surprises

The brain constantly predicts what will happen and only sends deviations
upward. Before acting, predict the expected outcome in one sentence. If
the actual outcome matches the prediction, log one line and move on. If it
diverges, report the surprise explicitly — the surprise is the signal.

## Reflex arc vs cortex (the traffic light is neural)

- 🟢 GREEN = spinal reflex: execute automatically, log it.
- ⚑ SEMI = reflex with a verification flag: execute, then flag for review.
- 🟡 YELLOW = cortical deliberation: propose, wait for the human.
- 🔴 RED = conscious question: no action without the human.

The tiers are not bureaucracy — they are the difference between a reflex
and a thought. Respect them like the nervous system does.

## Working memory → consolidation

- Working memory: the live session state (what is happening NOW).
- Consolidation: supervision.md, triage.md, audit.md (what becomes
  permanent). Never treat the working memory as durable — consolidate
  what matters.

## The invariant

Proposals are cheap; decisions are sacred. The hemispheres propose and
cross-check; the human decides. Nature optimized this for millions of
years — the workflow follows it.
