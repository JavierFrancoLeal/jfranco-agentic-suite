# @javierfrancoleal/compas

Created by **J.Franco**.

## Summary

When the model audits or optimizes Fanal for a platform, this skill runs
the DSH-derived checklist (one brain many skins, electron hardening, PWA
cache, token gate, batched state, client key silo, bundled runtime) and
applies ONLY what makes sense for a sovereign agentic orchestration
layer. It never over-engineers: DSH pieces that do not apply are
explicitly excluded.

## Use

Ask "compas" before shipping Fanal to any platform. The skill runs the
checker in the assets and reports `N ok · M to review` with the fixes.
